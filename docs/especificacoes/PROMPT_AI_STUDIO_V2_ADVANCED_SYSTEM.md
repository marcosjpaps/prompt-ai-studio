# PROMPT AI STUDIO V2 - ADVANCED SYSTEM

## Objetivo

Transformar o MVP em um SaaS profissional.

## Novos módulos

## Character Memory

Salvar personagens fixos:

-   rosto
-   cabelo
-   estilo
-   características
-   seed

## Product Memory

Salvar produtos:

-   nome
-   categoria
-   textura
-   cor
-   regras de preservação

## Biblioteca

-   templates
-   personagens
-   produtos
-   cenas
-   câmeras
-   iluminação

## Sistema de créditos

Free: limites básicos

Creator: mais gerações

Pro: recursos avançados

Agency: equipe e clientes

## IA avançada

Vision Analyzer: Analisa imagens.

Prompt Engine: Transforma análise em prompt.

Quality Checker: Encontra erros e melhora prompts.
